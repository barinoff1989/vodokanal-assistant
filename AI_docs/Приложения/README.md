# Приложения

Четыре документа, пришедшие из папок домашних заданий (`dz4`–`dz6`) и **остающиеся
каноническими**. Это не архив и не история: на каждый из них ссылаются действующие
документы проекта, а два хранят содержание, которого больше нигде нет.

| Документ | Зачем нужен |
|---|---|
| `Дашборды.html` | Спецификация дашборда наблюдаемости. Раздел 37.3 контекста прямо говорит: **полная таблица всех девяти алертов существует только здесь** — в контексте приведён один пример |
| `План теста RAG.html` | Метрики качества RAG, инструменты, требования к судье и эталонному набору. `Test_Plan.html` ссылается на него и намеренно **не дублирует**: качество RAG остаётся за этим документом |
| `Data_Catalog.html` | Каталог 16 источников данных с протоколами, режимами, узлами на диаграмме контейнеров и потребителями. Раздел 29 контекста даёт только сводную таблицу |
| `CTO_Challenge_report.html` | Отчёт верификации архитектуры. Разделы 24–25 пересказывают выводы и находки F1–F10, но сам отчёт — самостоятельный артефакт сдачи |

## Что осталось в папках `dz` и почему

**Устаревшие версии** — ранние копии диаграмм контейнеров и компонентов, схемы потоков
данных из `dz5`. Раздел 43 прямо объявляет последние отменёнными: они содержат уже
отменённую архитектуру доступа к Биллингу.

**Черновики** — `Quality_Security_Observability_v1.html`, ранний объединённый вариант,
заменённый тремя отдельными документами.

**Учебные материалы** — презентации курса и архив по алертингу. Это источники, из
которых считались цифры, а не артефакты проекта.

**Копии контекста версий 3.0 и 4.3** — история, причём вредная: описывают отменённые
решения.

## Что переносить сюда нельзя

`dz4/adr_1.md` и `dz4/adr_2.md` — черновики решения о хостинге модели с
**недостоверными цифрами**: 7,3 млн рублей, 53 дня, 800–1500 долларов в месяц, «Docker
Swarm» как выбранная технология. Раздел 26.4 контекста разбирает их подробно и
запрещает использовать как факты о проекте.

Перенос их сюда был бы прямо вреден: через полгода кто-то откроет папку решений, увидит
файл с заголовком «ADR-001» и статусом `Accepted` — и поверит. Раздел 34.1 описывает,
как ровно это уже произошло с фабрикацией «ADR-003» во внешнем ревью.
