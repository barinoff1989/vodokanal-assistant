# План: репозиторий только для сдачи — перенос остального на локальную машину

## Статус

**План, ничего не перенесено и не удалено.** Инвентаризация сделана по реальному дереву `AI_docs/` и
реальным ссылкам внутри пакета сдачи (grep, не по памяти). Открытые вопросы — в конце — нужно закрыть до
исполнения: часть решений не техническая, а про то, что́ считается «итоговым проектом».

## Принцип

**Перенос, не удаление.** Ничего не пропадает — процессные документы переезжают на локальную машину (вне
репозитория), в репозитории остаётся только то, что нужно для запуска системы и то, что нужно для
приёмки. Дополнительно — **git-тег на текущем состоянии до какой-либо правки**: вся история разработки
и так живёт в git-истории коммитов, но тег даёт быструю точку возврата без раскопок лога.

**Общий приём для «Источники для углубления».** В каждом ADR пакета такой раздел структурно один и тот
же: ссылка на детальный ADR/контекст/журнал «для тех, кто хочет углубиться» — именно то, что по условию
задачи не должно существовать в пакете сдачи. Заменяется одной строкой без путей, например: «Полная
история решения, замеры и альтернативы — в рабочем архиве разработки, вне пакета сдачи.» Факты и цифры,
которые сейчас стоят РЯДОМ со ссылкой (не сама ссылка), в тексте остаются — переносится не факт, а
путь к его происхождению.
